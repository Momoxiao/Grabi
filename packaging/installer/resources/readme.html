安装说明

  1. 继续完成安装，安装器会把 Grabi 放到 /Applications。
  2. 安装完成后打开 Grabi，并按提示授予“屏幕录制”权限。
  3. 授权后完全退出 Grabi，再重新打开一次。

授权路径

系统设置 → 隐私与安全性 → 屏幕与系统音频录制

首次打开被系统拦截时

当前 Grabi.app 使用 Apple Development 证书签名，安装器本身 尚未使用 Developer ID Installer 签名，也尚未完成 Apple 公证。请右键应用或 安装包 →“打开”→ 再确认一次；必要时进入“系统设置 → 隐私与安全性”点击“仍要打开”。

旧版本清理

安装器会在安装前退出正在运行的 Grabi，并清理旧的 LiteShot、Shutterbox， 以及用户目录里的重复 Grabi 副本，避免两个版本同时启动。

Grabi 是菜单栏应用，不显示 Dock 图标。安装完成后请查看菜单栏右侧的取景框图标。
